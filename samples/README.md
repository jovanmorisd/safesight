# Sample images

Ten images from the **test split** of the Ultralytics
[Construction-PPE dataset](https://docs.ultralytics.com/datasets/detect/construction-ppe/) (AGPL-3.0).
They were picked to include several workers per image and some workers without helmets, so they
exercise the compliance logic. They are for demos and smoke tests only; the full dataset is in
`datasets/construction-ppe/`, which git ignores.
